# Anwara Memorial Hospital — living specification

Responsive bilingual (English/Bengali) public hospital website for Anwara Memorial Hospital & Diagnostic Center in Satkhira, plus a cookie-session admin workspace.

Public flows: hospital story, founder history, services, doctors, gallery, contact, emergency phone/WhatsApp, and appointment requests. Admin flow: secure httpOnly cookie login, appointment status filtering and management, and super-admin creation of admin users.

Data model: appointments, admin_users, sessions. Public factual content and original media URLs are represented in the backend and frontend fallback data.
